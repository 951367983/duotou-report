一、多头排列选股规则（不含ST股）

1. 多头排列定义（三均线口径）

  • 5日、10日、20日均线依次向上排列：MA5 > MA10 > MA20（短期均线在长期均线之上、整体向上发散；已按你的要求剔除250日均线，只保留三条均线）；
  • 且收盘价站上5日均线（通达信公式保留条件）；
  • 范围：沪深A股白名单（sh 600/601/603/605，sz 000/001/002/003/300/301；剔除科创板688/689、北交所4xx/8xx/9xx）；剔除ST股（课程中学员问过"均线多头排列不剔除st股吗"，按你的要求一律剔除）；
  • 本页统计为不复权口径，与软件前复权显示存在小幅差异（除权日附近），趋势判断不受影响。

2. 选股三核心条件（课程老师明确）

  1. 多头排列：均线向上发散，是前提；
  2. 前三日内创出新高：从阴线之后开始数，有一天创新高即可（不用连续三根）；
  3. 触及（跌破）5日线或10日线、绿盘低吸：这里的"触"是破线买入，偏离太远不买。

3. 方向与约束

  • 只在主流板块里选（市场阻力最小处；老师早盘策略的板块=主流题材），主流板块里再精选多头排列；
  • 多头排列 + 业绩好（看不清业绩就看K线、只看涨幅3%/4%以上的票）；
  • 不做多头排列后排（涨幅不到3%的票）；
  • 次新股不适合（换手过高、均线未走顺）；
  • 中长线持股≤3只、做组合；大跌大买、大涨大卖、小阴小跌不动、只低吸不追高。

二、买入优先排序及理由

  • 第1优先：主流题材内的前排龙头理由：市场阻力最小处，赚钱效应最强；同一题材里优先多头排列+业绩；龙头有资金承接、有辨识度。课程："在主流板块里选""有龙头谁干后排"。
  • 第2优先：多头排列 + 业绩好的票理由："多头排列+业绩交易模式基本上涵盖了市场所有的牛股，或者即将启动的牛股"；业绩好的票基本上都有机构参与，抗风险能力强。
  • 第3优先：抗跌强势股理由：别人跌的时候它几乎不跌、指数企稳它就涨停（课程判定强势的标准）；指数下跌末期启动大牛，跌出新高。
  • 第4优先：三日新高 + 回踩5日/10日线低吸位理由：这是课程唯一的买点前提与位置要求——"多头排列的票就看三日是否新高，其它技术不要看"；在5日/10日线破线位置低吸，成本低、止损近。
  • 第5优先：辅助买点信号加分（金针探底 / 上影线 / 缺口 / 串阳）理由：金针探底=急跌跌不下去（只适合前排/龙头）；上影线=前日"奋斗过"次日低吸；缺口=心理支撑、筹码稳定；四串阳=资金介入、可能高低切。叠加信号越多越优先。
  • 第6优先：趋势科技与蓝筹科技组合搭配理由：组合策略——2只趋势科技（历史新高震荡上行）+1只蓝筹科技（箱体震荡上行、业绩优先），或1趋势+2蓝筹；轮动上涨、降低单票风险。课程："大跌大买，大涨大卖。小阴小跌，就不要动。只低吸，别追高。"
实际买入时按"主流题材 → 多头排列+业绩 → 抗跌强势 → 三日新高 → 回踩低吸位 → 信号加分"逐层过滤排序；当日多头排列名单仅是第一步筛选。

三、买卖技巧整体

买点（低吸系统）

  • 主买点：多头排列 + 前三日新高 + 回踩（跌破）5日或10日线绿盘低吸；
  • 金针探底：多头排列内急跌-3%左右跌不下去、分时走W、尾盘收回，只适合多头排列前排/龙头；
  • 上影线：主流票 + 前日上影线"奋斗过" + 次日下影低吸；
  • 缺口：心理支撑/筹码稳定；指数下跌时强势股不破缺口可低吸；缺口破了短期内不修复则放弃；
  • 串阳：连续小阳有资金介入；四串阳=可能高低切，次日低吸可能大肉；
  • 五日攀（主升浪）：每天下杀到收盘5天线附近埋伏，可提前算明日5天线价位；
  • 铁律：业绩好的票主升浪千万不能追高，只能水下低吸。

持股与趋势判断

  • 短线强弱看5日线（不破5日线算强势）；中期看10日线、20日线；20日线是大牛股的生命线；
  • 主升浪特征：3天一个新高；主升浪票一般10日线有极强支撑；赶顶段天天新高；
  • 主升浪完结信号：超级大阴线、日内大震荡（K线会明确告诉你）；
  • 月线大牛股：沿5月线向上、10月线强烈支撑；每月第一天看止跌、最后一天看是否还在5月线；
  • 破20日线三天上不去就扔；如果止跌它还是牛股；多头排列的票调整一般看三天。

卖出（课程 8 大卖点）

  1. 连续猛拉尾盘 → 尾盘卖；
  2. 早冲高、下午再拉没过早上高点（或过了没迅速远离）→ 卖；
  3. 冲高摸板差1分 / 该上板不上板 → 先卖；
  4. 小阳连续堆积、大阳见顶 → 跑路；
  5. 板块联动、龙头涨停 → 卖跟风小弟；
  6. 破高反跌 → 卖；
  7. 破日内均线 → 卖；
  8. 买错则基本卖不对（止损纪律）。

卖出原则："果断、猛烈""不怕卖飞、卖飞永远正确"；止盈什么时候都是对的。

止损与仓位

  • 止损：一般选手成本价止损、激进者3%；大题材做错可多拿一天/熬一熬，小题材直接止损；
  • 仓位：持股≤3只；2趋势+1蓝筹或1趋势+2蓝筹；大跌大买、大涨大卖、小阴小跌不动、只低吸不追高。

四、每日复盘流程（中长线做短）

  1. 每天盘后用通达信把多头排列选出来（ctrl+T 条件选股）；
  2. 看即将走主升浪的，加入中长线股票池；
  3. 复盘看盘面在炒什么：多头排列 + 业绩 + 同题材；
  4. 看股票池谁创新高（不是拉尾盘的，次日绿盘低吸）；
  5. 四串阳关注（高低切信号）；
  6. 结合大盘指数：大跌好选股；指数企稳后，多头排列抗跌的票十分好做。

五、多头排列数量 = 市场温度计

  • 低于冰点参考线（272只，三均线口径历史25%分位）≈ 情绪冰点——可大胆试错；但需盘面配合（赚钱效应好时不算冰点）；
  • 数量持续回升 = 市场回暖；
  • 数量高位 = 结构性业绩牛 / 过热警惕；
  • 与涨停板数量一起看，双指标判断市场温度；
  • 本页每日自动统计该数值，配合冰点参考线直观观察。
